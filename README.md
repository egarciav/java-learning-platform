# Java Learning Platform 🚀

Plataforma web interactiva completa para aprender Java desde nivel Junior hasta Mid Level, incluyendo Spring Boot, JPA, Concurrencia y Testing.

## 📚 Contenido Completo

Esta plataforma cubre **todos los conceptos esenciales** de Java de manera progresiva con más de **50 ejemplos prácticos**:

### 1. **Conceptos Básicos** (Junior)
- Tipos primitivos y wrappers
- Variables y constantes
- Operadores (aritméticos, lógicos, relacionales)
- Conversión entre tipos (casting)
- Entrada y salida básica

### 2. **Estructuras de Control** (Junior)
- Condicionales (if-else, switch, operador ternario)
- Bucles (for, while, do-while, enhanced for)
- Control de flujo (break, continue, return)
- Etiquetas en loops

### 3. **Programación Orientada a Objetos** (Junior-Mid)
- Clases y objetos
- Constructores y sobrecarga
- Herencia y super
- Polimorfismo (sobrecarga y sobreescritura)
- Encapsulamiento y modificadores de acceso
- Métodos estáticos y final

### 4. **Colecciones y Arrays** (Junior-Mid)
- Arrays unidimensionales y multidimensionales
- ArrayList y operaciones
- HashMap y LinkedHashMap
- HashSet y TreeSet
- Comparación y cuándo usar cada colección

### 5. **Manejo de Excepciones** (Mid)
- Try-catch-finally
- Jerarquía de excepciones
- Checked vs Unchecked exceptions
- Excepciones personalizadas
- Try-with-resources
- Buenas prácticas

### 6. **Conceptos Intermedios** (Mid)
- Interfaces y herencia múltiple
- Clases abstractas
- Generics (tipos genéricos)
- Enums (tipos enumerados)
- Records (Java 14+)

### 7. **Streams y Expresiones Lambda** (Mid)
- Expresiones Lambda
- Method References
- Stream API (filter, map, reduce)
- Operaciones intermedias y terminales
- Optional para manejo de nulos
- Collectors avanzados

### 8. **Concurrencia y Threads** (Mid)
- Creación de threads (Thread, Runnable)
- Sincronización y locks
- Problemas de concurrencia
- ExecutorService y Thread Pools
- CompletableFuture
- Colecciones concurrentes

### 9. **File I/O** (Mid)
- Lectura y escritura con java.io
- BufferedReader y BufferedWriter
- Try-with-resources
- NIO (java.nio.file) - API moderna
- Operaciones de archivos y directorios

### 10. **JPA y Entidades** (Mid)
- Anotaciones JPA (@Entity, @Table, @Column)
- Claves primarias y generación
- Relaciones (OneToMany, ManyToOne, ManyToMany, OneToOne)
- Cascade y FetchType
- Ciclo de vida de entidades

### 11. **Spring Core** (Mid)
- Inversión de Control (IoC)
- Inyección de Dependencias (DI)
- Beans y Scopes
- @Component, @Service, @Repository
- @Autowired, @Qualifier, @Primary
- Ciclo de vida de beans

### 12. **Spring Boot** (Mid)
- Configuración y estructura
- Controladores REST (@RestController)
- Servicios y lógica de negocio
- Repositorios JPA
- DTOs y validación
- Manejo global de excepciones
- ResponseEntity y códigos HTTP

### 13. **Testing** (Mid)
- JUnit 5 fundamentos
- Assertions completas
- Mockito para mocking
- @Mock, @InjectMocks
- Tests parametrizados
- Mejores prácticas de testing

## 🚀 Instalación y Uso

### Requisitos previos
- Node.js (versión 14 o superior)
- npm o yarn

### Instalación

```bash
# Clonar el repositorio (si aplica)
git clone <url-del-repositorio>

# Navegar al directorio del proyecto
cd java-learning-platform

# Instalar dependencias
npm install

# Iniciar el servidor de desarrollo
npm start
```

La aplicación se abrirá automáticamente en [http://localhost:3000](http://localhost:3000)

## 📖 Cómo usar esta plataforma

1. **Navega por las secciones** usando el menú superior
2. **Lee las descripciones** de cada concepto
3. **Expande el código** haciendo clic en "Ver Código"

6. **Progresa gradualmente** desde conceptos básicos hasta Spring Boot

## 🎓 Ruta de Aprendizaje Recomendada

1. Comienza con **Conceptos Básicos** para establecer fundamentos sólidos
2. Continúa con **Estructuras de Control** para aprender lógica de programación
3. Domina **POO** antes de avanzar a temas más complejos
4. Aprende **Colecciones** para manejar datos eficientemente
5. Estudia **Excepciones** para crear código robusto
6. Profundiza en **Conceptos Intermedios** para prepararte para Spring Boot
7. Finaliza con **Spring Boot** para desarrollo empresarial
